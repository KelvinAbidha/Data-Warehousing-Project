# **Assignment Details**

# **Assignment 1: NoSQL Data Processing (10 Marks)**

* **Task:** Process and analyze large-scale structured/unstructured data using NoSQL storage solutions.  
* **Required Tools:** Apache ecosystem, Python.  
* **Database Systems:**  
  * **MongoDB:** Implementation focus on indexing strategies and query optimization.  
  * **Cassandra:** Distributed architecture setup and data modeling.  
* **Dataset:** Nairobi Securities Exchange (NSE) Data *(To be distributed by the lecturer)*.

# **Assignment 2: Graph Data Analytics (10 Marks)**

* **Task:** Build analytics models and visualize complex entities and their interactions using graph database structures.  
* **Tool:** Neo4j (access via Neo4j.com).  
* **Core Concepts:** Nodes (entities) and Links (relationships).  
* **Dataset:** Traffic Data.  
* **Implementation Details:**  
  * Model **"Accidents"** and **"Traffic"** as core nodes.  
  * Define and rate relationships based on severity parameters (e.g., classifying impact levels such as "severe").

# **Final Deliverable (10 Marks)**

* **Submission Requirement:** Prepare and submit a comprehensive Summary Report that thoroughly documents the methodology, implementation code, schema designs, and analytical findings for both Assignment 1 and Assignment 2\.
